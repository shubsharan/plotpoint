# Epic: Prove the Policy Loop

## Outcome

A team can use Plotpoint to measure how runtime economic policies change a controlled company-research agent's behavior and outcomes, then select an evidence-backed operating policy.

## Done When

- Across a representative versioned task dataset, materially different policies produce explainable behavioral differences; Plotpoint reconciles costs, evaluates quality, latency, and reliability, and produces a reproducible recommendation with uncertainty and provenance that we would deploy ourselves.
