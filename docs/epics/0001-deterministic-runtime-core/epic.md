# Epic: Deterministic Runtime Core

## Outcome

Game authors can define, execute, explain, and test durable state transitions and progression across player, team, and session aggregates without ambient I/O or platform infrastructure.

## Done When

- Representative command and progression models produce identical canonical results from identical explicit inputs, reject invalid state and stale versions without mutation, isolate aggregate changes, and terminate automatic progression with explicit diagnostics.
